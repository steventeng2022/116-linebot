# 社群小幫手 LINE Bot

社群團隊使用的 LINE Bot，提供成員身分登記、活動出席回覆、分工及管理員網頁。

## 功能

- 私訊輸入 `身分驗證`，依序填寫姓名、班級與座號
- 沒有加入官方帳號的群組成員，可由網站手動建立身分，再於群組輸入 `/綁定身分 一次性代碼`
- 管理員會收到 LINE 推播通知
- `https://bot.steventeng.uk` 提供最高權限管理控制台
- 網站可修改／刪除成員、活動、工作類別、回覆名單與分工
- `/event 活動名稱` 或網站建立活動後，自動私訊所有已驗證成員
- LINE 群組建立活動時會同步顯示出席按鈕，未加官方帳號但已綁定的成員也能填寫
- 成員可選擇有空／沒空，網站會統計未回覆名單與傳送狀態
- 預設工作為音控、簡報、攝影、機動，可新增、改名或刪除
- 每個活動可指派一人多項工作、加入備註並列印／輸出 PDF 分工表
- 管理員可在 LINE 使用 `/指派 姓名 工作 備註`、`/移除指派 姓名 工作` 及 `/分工表`
- 管理網站可新增、修改、刪除及匯出公服時數，並查看每位成員累計
- 公服時數可選擇連結既有活動；成員在 LINE 輸入 `公服時數` 可查自己的紀錄
- 網站可建立、修改與移除管理員帳號，密碼以 scrypt 雜湊保存
- 管理員帳號可連結已驗證的 LINE 成員，統一授予或撤銷 Bot 管理權
- 操作紀錄頁保留網站登入、管理操作與 LINE Bot 活動，不記錄密碼或訊息內容
- `/list` 查看最新活動名單

## 本機測試

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python smoke_test.py
```

環境變數請參考 `.env.example`。不要提交真正的 LINE Token、密碼或資料庫。

## Cloudflare 網域代理

`worker.js` 只負責將 `bot.steventeng.uk` 的流量串流轉送到 Linode HTTPS 來源；應用程式與學生資料不儲存在 Cloudflare。`wrangler.jsonc` 讓 Cloudflare GitHub Builds 可以驗證並部署這個代理層。

## 管理員權限

第一次升級時，系統會將環境變數中的既有管理員帳號與密碼安全移轉到資料庫。
之後請從網站的「管理員」頁建立帳號、重設密碼，並選擇要授予 Bot 管理權的 LINE 成員。
只有連結 LINE 身分的管理員可以使用 `/event` 群發活動；舊的 `/設定管理員` 指令已停用。
